## Each index traps against the taller shoulder

Given non-negative elevation `height`, compute how much rain fills depressions after a storm. For `[0,1,0,2,1,0,1,3,2,1,2,1]`, the answer is 6 — units sit in valleys where a left and right wall exist.

Per index `i`, water level is `min(maxLeft[i], maxRight[i]) - height[i]` when positive. Prefix max arrays solve it in O(n) time and O(n) space — fine, but the interview usually wants the **two-pointer** version that tracks running left and right maxes while squeezing from both ends.

The invariant: process the shorter side. If `height[left] <= height[right]`, the left bar's trapped water is determined by `leftMax` alone — whatever happens on the right, `rightMax` is at least `height[right]`, so the bottleneck for `left` is `leftMax`.

## Two pointers inward

Initialize `left = 0`, `right = n-1`, `leftMax = 0`, `rightMax = 0`, `water = 0`.

While `left < right`:
- If `height[left] <= height[right]`: update `leftMax`, add `leftMax - height[left]` to water, `left++`.
- Else: symmetric on the right.

<Steps>
<Step title="Start pointers at both ends with zero maxes">
  No water trapped until a wall exists on the processed side.
</Step>
<Step title="Always advance the side with the smaller current height">
  The taller opposite side guarantees a shoulder for the shorter side.
</Step>
<Step title="Accumulate max minus current height when positive">
  Negative contribution means the bar is the new max — add zero.
</Step>
</Steps>

## Solution

```ts
function trap(height: number[]): number {
  let left = 0;
  let right = height.length - 1;
  let leftMax = 0;
  let rightMax = 0;
  let water = 0;

  while (left < right) {
    if (height[left] <= height[right]) {
      leftMax = Math.max(leftMax, height[left]);
      water += leftMax - height[left];
      left++;
    } else {
      rightMax = Math.max(rightMax, height[right]);
      water += rightMax - height[right];
      right--;
    }
  }

  return water;
}
```

Time **O(n)**. Space **O(1)**.

Prefix-array and monotonic-stack variants also work; two pointers is the cleanest O(1)-space story.

## In an interview

Example: `[0,1,0,2,1,0,1,3,2,1,2,1]` → 6. Confirm non-negative heights, array not a circle.

State formula `min(L,R) - h[i]`, then offer prefix arrays, then optimize to two pointers with the shorter-side rule.

Follow-ups: 03.35 Trapping Rain Water II, which index holds most water, stack-based variant. Bug: advancing the taller side first — breaks the guarantee that the opposite max is a valid bound.
