## `*` here means anything, including nothing

Given string `s` and pattern `p`, return whether they match. `?` matches exactly one character. `*` matches **any sequence of characters, including empty** — a different contract from 03.31 Regular Expression Matching, where `*` quantifies only the previous token.

`"adceb"` vs `"*a*b"` matches. `"aa"` vs `"a"` does not — no partial credit. `"abc"` vs `"a*bc"` matches because `*` can swallow `"bc"`... wait, `*` matches any sequence; `"a*bc"` on `"abc"`: `a` matches `a`, `*` matches empty, `bc` matches `bc`. Good.

Naive recursion tries every split of `*` across the remaining string — O(2^n) in the worst case when the pattern is mostly stars. The fix is the same subproblem shape as regex DP, but the `*` transition is simpler: `dp[i][j] = dp[i][j-1] || dp[i-1][j]` (skip star or extend match).

## Table DP

`dp[i][j]` = whether `s[0..i-1]` matches `p[0..j-1]`.

- `p[j-1] === '?'` or equal char: `dp[i][j] = dp[i-1][j-1]`.
- `p[j-1] === '*'`: `dp[i][j] = dp[i][j-1] || dp[i-1][j]` — star matches empty, or star absorbs one more char.
- Row 0: `dp[0][j] = dp[0][j-1]` when `p[j-1]==='*'`.

## Solution

```ts
function isMatch(s: string, p: string): boolean {
  const m = s.length;
  const n = p.length;
  const dp: boolean[][] = Array.from({ length: m + 1 }, () =>
    Array(n + 1).fill(false)
  );
  dp[0][0] = true;

  for (let j = 1; j <= n; j++) {
    if (p[j - 1] === "*") dp[0][j] = dp[0][j - 1];
  }

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (p[j - 1] === "*") {
        dp[i][j] = dp[i][j - 1] || dp[i - 1][j];
      } else if (p[j - 1] === "?" || p[j - 1] === s[i - 1]) {
        dp[i][j] = dp[i - 1][j - 1];
      }
    }
  }

  return dp[m][n];
}
```

Time **O(m · n)**. Space **O(m · n)**, or **O(n)** with one row.

An optimized **O(m + n)** greedy exists: keep `starIdx` and `matchIdx` — on mismatch, rewind to last `*` and advance one char in `s`. Worth mentioning in interview follow-ups; the table version is easier to get correct under pressure.

## In an interview

Example: `s = "adceb"`, `p = "*a*b"` → true. Contrast with 03.31: here `*` stands alone and eats arbitrary text.

State `dp[i][j]` or describe greedy: on `*`, remember position; on mismatch, backtrack star to consume one more char.

Follow-ups: O(1) space greedy, match from right to left, 03.31 regex variant. Bug: using regex `*` rules (`a*` quantifier) instead of wildcard `*` (any sequence).
