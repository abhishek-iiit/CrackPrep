## Split the string at every boundary — naive palindrome checks repeat work

Given a string `s`, partition it so every part is a palindrome. Return all partitions. `"aab"` → `[["a","a","b"], ["aa","b"]]`.

Backtracking tries every cut: from index `start`, pick `end` such that `s[start..end]` is a palindrome, push that substring, recurse on `end + 1`, pop. Without preprocessing, each palindrome test is O(n) and you run it at every node — on a string of length 16 that adds up across the 2^(n−1) cut tree.

Precompute `isPalin[i][j]` in O(n²) once. Then each branch check is O(1).

## Backtrack cuts with a palindrome table

Build `isPalin[i][j]` bottom-up: single chars true, expand outward for longer substrings (or fill diagonally). DFS from `start`: loop `end` from `start` to n−1; if `isPalin[start][end]`, add `s.slice(start, end + 1)` to path, recurse from `end + 1`.

The invariant: `path` holds a list of palindrome substrings covering `s[0..start-1]`. When `start === n`, copy `path` to result.

<Steps>
<Step title="Precompute isPalindrome">
  For each center or each `(i, j)` pair with `i <= j`, mark whether `s[i..j]` reads the same forward and backward.
</Step>
<Step title="DFS from start index">
  Try extending the current part to every `end` where `isPalin[start][end]`.
</Step>
<Step title="Collect at start === n">
  Full string consumed — one valid partition.
</Step>
</Steps>

## Solution

```ts
function partition(s: string): string[][] {
  const n = s.length;
  const isPalin: boolean[][] = Array.from({ length: n }, () =>
    Array(n).fill(false)
  );

  for (let i = n - 1; i >= 0; i--) {
    for (let j = i; j < n; j++) {
      isPalin[i][j] =
        s[i] === s[j] && (j - i <= 2 || isPalin[i + 1][j - 1]);
    }
  }

  const result: string[][] = [];
  const path: string[] = [];

  function backtrack(start: number): void {
    if (start === n) {
      result.push([...path]);
      return;
    }
    for (let end = start; end < n; end++) {
      if (!isPalin[start][end]) continue;
      path.push(s.slice(start, end + 1));
      backtrack(end + 1);
      path.pop();
    }
  }

  backtrack(0);
  return result;
}
```

Time **O(n × 2^n)** worst case for enumeration (every substring is a palindrome on strings like `"aaa..."`), plus **O(n²)** preprocessing. Space **O(n²)** for the table plus **O(n)** recursion depth.

## In an interview

Restate: every part must be palindrome, return all partitions. Example `"aab"`. Note exponential output in worst case.

Say: backtrack cut positions, precompute palindrome intervals in O(n²) so DFS stays clean. Draw the tree for `"aab"`: cut after first `a`, after `aa`, etc.

Follow-ups: **Palindrome Partitioning II** (minimum cuts), or return one partition only. Bug: off-by-one on `end` in slice (`end + 1` exclusive), or forgetting empty string edge (single char always works).
