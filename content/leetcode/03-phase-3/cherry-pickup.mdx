## One round trip is two simultaneous forward paths

An `n × n` grid holds cherries (`1`), empty cells (`0`), or thorns (`-1`). Start `(0,0)`, end `(n-1,n-1)`, move only right or down. Collect cherries on arrival (once per cell). Return max cherries.

The naive there-and-back DP doubles state. The trick: run **two walkers** from start to end **at the same time**. After `t` moves, walker 1 is at `(r1,c1)`, walker 2 at `(r2,c2)` with `r1+c1 = r2+c2 = t` — same total steps, so `c2 = r1 + c1 - r2`.

State: **`dp[r1][c1][r2]`** = max cherries when walkers occupy those positions after the same number of steps. Each step both move right or down — four combinations of prior states. If both land on the same cherry cell, count it once.

Thorns (`-1`) invalidate a state. Unreachable states stay at `-1`.

## 3D DP transitions

Initialize `dp[0][0][0] = grid[0][0]`. Iterate `r1`, then `c1`, then `r2`; derive `c2`. Skip invalid or thorn cells.

Previous states (each walker moved one step from):
- Both down: `(r1-1,c1,r2-1)`
- Walker1 down, walker2 right: `(r1-1,c1,r2)`
- Walker1 right, walker2 down: `(r1,c1-1,r2-1)`
- Both right: `(r1,c1-1,r2)`

Add cherries: `grid[r1][c1] + grid[r2][c2]`, minus one if same cell.

## Solution

```ts
function cherryPickup(grid: number[][]): number {
  const n = grid.length;
  const dp = Array.from({ length: n }, () =>
    Array.from({ length: n }, () => Array(n).fill(-1))
  );
  dp[0][0][0] = grid[0][0];

  for (let r1 = 0; r1 < n; r1++) {
    for (let c1 = 0; c1 < n; c1++) {
      for (let r2 = 0; r2 < n; r2++) {
        const c2 = r1 + c1 - r2;
        if (c2 < 0 || c2 >= n) continue;
        if (grid[r1][c1] === -1 || grid[r2][c2] === -1) continue;
        if (r1 === 0 && c1 === 0 && (r2 !== 0 || c2 !== 0)) continue;

        let gain = grid[r1][c1];
        if (r1 !== r2 || c1 !== c2) gain += grid[r2][c2];

        let best = -1;
        const relax = (pr1: number, pc1: number, pr2: number) => {
          if (pr1 >= 0 && pc1 >= 0 && pr2 >= 0 && dp[pr1][pc1][pr2] >= 0) {
            best = Math.max(best, dp[pr1][pc1][pr2]);
          }
        };

        relax(r1 - 1, c1, r2 - 1);
        relax(r1 - 1, c1, r2);
        relax(r1, c1 - 1, r2 - 1);
        relax(r1, c1 - 1, r2);

        if (best >= 0) dp[r1][c1][r2] = best + gain;
      }
    }
  }

  return Math.max(0, dp[n - 1][n - 1][n - 1]);
}
```

Time **O(n³)**. Space **O(n³)**, reducible to **O(n²)** with rolling layers over step count.

## In an interview

Small 3×3 with cherries and one thorn — show why return trip equals two synchronized walkers.

Define `dp[r1][c1][r2]` and derive `c2` from equal step counts before loops.

Follow-ups: Cherry Pickup II (any number of trips), print paths, O(n²) space. Bug: counting `grid[r1][c1]` twice when walkers share a cell.
