## Shortest is not enough — enumerate them all

Same rules as 03.22 Word Ladder: one letter changed per step, every word must be in `wordList`. Return **all** shortest transformation sequences from `beginWord` to `endWord`. If none exist, return `[]`.

Running BFS until you hit `endWord` gives one shortest path. Running BFS again and again with words removed finds others, but that is fragile and not obviously correct when multiple branches reconverge. The clean split: **BFS assigns each word its minimum distance from `beginWord` and records only edges that advance one level**; **DFS from `endWord` walks backward along those edges** to emit every full chain.

The traps: including a longer path because you did not freeze the BFS layer when the end was first reached; duplicate paths from redundant edges in the graph; forgetting to reverse paths built from end to start.

## Layered BFS, then backward DFS

BFS level by level. When exploring `word → next`, add directed edge `word → next` only if `next` is unseen (first time at this depth) or already at depth `dist[word] + 1` (parallel shortest route). Stop adding new words once `endWord` has been assigned a distance — deeper words cannot belong to a shortest ladder.

Then DFS from `endWord`: at each step, move to predecessors whose distance is exactly one less. When you reach `beginWord`, reverse the collected path and append to results.

## Solution

```ts
function findLadders(
  beginWord: string,
  endWord: string,
  wordList: string[]
): string[][] {
  const words = new Set(wordList);
  if (!words.has(endWord)) return [];

  const neighbors = (word: string): string[] => {
    const res: string[] = [];
    for (let i = 0; i < word.length; i++) {
      for (let c = 97; c <= 122; c++) {
        const ch = String.fromCharCode(c);
        if (ch === word[i]) continue;
        const next = word.slice(0, i) + ch + word.slice(i + 1);
        if (words.has(next)) res.push(next);
      }
    }
    return res;
  };

  const graph = new Map<string, string[]>();
  const dist = new Map<string, number>();
  dist.set(beginWord, 0);

  let frontier = new Set<string>([beginWord]);
  let reachedEnd = false;

  while (frontier.size && !reachedEnd) {
    for (const w of frontier) words.delete(w);

    const nextFrontier = new Set<string>();
    for (const w of frontier) {
      for (const nxt of neighbors(w)) {
        if (!graph.has(w)) graph.set(w, []);
        if (!dist.has(nxt)) {
          graph.get(w)!.push(nxt);
          dist.set(nxt, dist.get(w)! + 1);
          nextFrontier.add(nxt);
          if (nxt === endWord) reachedEnd = true;
        } else if (dist.get(nxt) === dist.get(w)! + 1) {
          graph.get(w)!.push(nxt);
        }
      }
    }
    frontier = nextFrontier;
  }

  if (!dist.has(endWord)) return [];

  const result: string[][] = [];
  const path: string[] = [endWord];

  const dfs = (word: string): void => {
    if (word === beginWord) {
      result.push([...path].reverse());
      return;
    }
    for (const prev of graph.get(word) ?? []) {
      if (dist.get(prev)! + 1 === dist.get(word)) {
        path.push(prev);
        dfs(prev);
        path.pop();
      }
    }
  };

  dfs(endWord);
  return result;
}
```

BFS is **O(n · L · 26)** as in 03.22; DFS cost is proportional to the number of shortest paths (exponential in the worst case). Space **O(n)** for maps plus output.

## In an interview

Clarify: all **shortest** ladders only; order of sequences in output usually unconstrained; return `[]` if impossible. Walk the `"hit" → "cog"` example and show two equal-length routes if both exist.

Explain the two phases before coding: BFS for distances + forward edges on shortest layers, then DFS backward. Mention stopping BFS once `endWord` gets its label.

Follow-ups: bidirectional BFS for distance only, return count of shortest paths without listing them. Bug: continuing BFS after the end level and polluting the graph with longer edges.
