## Increasing edges mean DAG — memoize the DAG

Given an `m × n` integer matrix, find the longest path moving up/down/left/right where each step goes to a **strictly larger** value. Values can repeat in the matrix, but you cannot revisit cells.

`[[9,9,4],[6,6,8],[2,1,1]]` → 4: path `1 → 2 → 6 → 9` (or through 8 depending on layout).

Naive DFS from every cell without memo revisits subproblems exponentially. Because moves only go to **strictly higher** values, there is **no cycle** — the graph is a DAG. `dfs(r,c)` = 1 + max DFS of valid larger neighbors, cached in `memo[r][c]`.

Each cell computed once → **O(m · n)** total after memoization.

## DFS + memo from every start

Four directions. From `(r,c)`, try neighbors with strictly greater value. Take max chain length + 1. Track global max over all starting cells.

<Steps>
<Step title="Allocate memo[m][n] initialized to 0 (uncomputed)">
  Zero means not yet visited by DFS; path length is at least 1 everywhere.
</Step>
<Step title="For each cell, dfs(r,c) if memo unset">
  Explore four neighbors with matrix[nr][nc] > matrix[r][c].
</Step>
<Step title="Return global maximum memo value">
  Longest path may start anywhere — not only corners.
</Step>
</Steps>

## Solution

```ts
function longestIncreasingPath(matrix: number[][]): number {
  const m = matrix.length;
  const n = matrix[0].length;
  const memo = Array.from({ length: m }, () => Array(n).fill(0));
  const dirs = [
    [0, 1],
    [0, -1],
    [1, 0],
    [-1, 0],
  ];

  function dfs(r: number, c: number): number {
    if (memo[r][c]) return memo[r][c];
    let best = 1;
    for (const [dr, dc] of dirs) {
      const nr = r + dr;
      const nc = c + dc;
      if (
        nr >= 0 &&
        nr < m &&
        nc >= 0 &&
        nc < n &&
        matrix[nr][nc] > matrix[r][c]
      ) {
        best = Math.max(best, 1 + dfs(nr, nc));
      }
    }
    memo[r][c] = best;
    return best;
  }

  let ans = 0;
  for (let r = 0; r < m; r++) {
    for (let c = 0; c < n; c++) {
      ans = Math.max(ans, dfs(r, c));
    }
  }
  return ans;
}
```

Time **O(m · n)**. Space **O(m · n)** for memo and recursion stack in worst case.

Topological sort + DP is an equivalent O(mn) approach if recursion depth is a concern on tall matrices.

## In an interview

Walk 3×3 example → 4. Confirm 4-direction, strict increase, no reuse.

State DAG argument before coding — cycles impossible, so memo is safe.

Follow-ups: print path, k longest paths, wrap-around torus (changes problem). Bug: using `>=` instead of `>` which creates cycles and infinite recursion without memo guards.
