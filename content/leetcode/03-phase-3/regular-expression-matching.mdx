## `*` is not a wildcard — it quantifies the previous token

Given string `s` and pattern `p`, decide whether the full string matches the full pattern. `.` matches any single character. `*` matches **zero or more** of the character immediately before `*` — not "anything," unlike wildcards in 03.32 Wildcard Matching.

`"aa"` vs `"a*"` matches (`*` eats both a's). `"aab"` vs `"c*a*b"` matches (`c*` zero times, `a*` twice, then `b`). `"mississippi"` vs `"mis*is*p*."` does not — the greedy mental model fails on overlapping `*` choices.

Backtracking every split at each `*` is exponential. The repeating subproblem: **does `s[0..i-1]` match `p[0..j-1]`?** That is exactly 2D DP, same table shape as 03.27 Edit Distance but boolean and with different transition rules.

## The dp recurrence

`dp[i][j]` = whether prefix `s[0..i-1]` matches prefix `p[0..j-1]`.

Base: `dp[0][0] = true`. For pattern-only prefixes, only even-length patterns ending in `x*` can match empty string — e.g. `a*b*` on `""`.

When `p[j-1]` is not `*`: match if chars equal or pattern char is `.`, and `dp[i-1][j-1]`.

When `p[j-1]` is `*`: two branches always:
1. **Zero occurrences** — ignore `x*`, look at `dp[i][j-2]`.
2. **One or more** — if `p[j-2]` matches `s[i-1]` (or is `.`), inherit `dp[i-1][j]` (consume one char, `*` stays).

<Steps>
<Step title="Initialize row 0 for patterns matching empty s">
  Walk `j` by 2; if `p[j-1]==='*'`, set `dp[0][j] = dp[0][j-2]`.
</Step>
<Step title="Fill dp[i][j] for i from 1 to m, j from 1 to n">
  Branch on whether `p[j-1]` is `*` or a literal / `.`.
</Step>
<Step title="Return dp[m][n]">
  Full string matched iff the full pattern is consumed consistently.
</Step>
</Steps>

## Solution

```ts
function isMatch(s: string, p: string): boolean {
  const m = s.length;
  const n = p.length;
  const dp: boolean[][] = Array.from({ length: m + 1 }, () =>
    Array(n + 1).fill(false)
  );
  dp[0][0] = true;

  for (let j = 2; j <= n; j++) {
    if (p[j - 1] === "*") dp[0][j] = dp[0][j - 2];
  }

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (p[j - 1] === "*") {
        dp[i][j] = dp[i][j - 2];
        if (p[j - 2] === "." || p[j - 2] === s[i - 1]) {
          dp[i][j] = dp[i][j] || dp[i - 1][j];
        }
      } else if (p[j - 1] === "." || p[j - 1] === s[i - 1]) {
        dp[i][j] = dp[i - 1][j - 1];
      }
    }
  }

  return dp[m][n];
}
```

Time **O(m · n)**. Space **O(m · n)**, or **O(n)** with one rolling row if you only need the answer.

## In an interview

Example: `s = "aab"`, `p = "c*a*b"` → true. Clarify: `.` is one char, `*` always pairs with the previous pattern character, full match required.

State subproblem before coding: `dp[i][j]` = match for prefixes. Call out the `*` branches: zero (`j-2`) vs consume (`i-1,j` when char before `*` matches).

Follow-ups: 03.32 Wildcard Matching, count all matches, iterative without extra space. Bug to mention first: treating `*` as standalone wildcard — it always quantifies `p[j-2]`, so `*` at index 0 is invalid input on LeetCode but your loop should still assume valid patterns.
