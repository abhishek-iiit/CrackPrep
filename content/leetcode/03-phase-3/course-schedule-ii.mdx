## An order, not just a yes

There are `numCourses` labeled `0 … numCourses-1` and prerequisite pairs `[a, b]` meaning take `b` before `a`. Return **any** valid ordering to finish all courses. If impossible (cycle), return `[]`.

01.28 Course Schedule returns a boolean — same graph, same cycle test. Here you must **emit** the order. DFS post-order topological sort works but is easier to mishandle (cycle detection mid-recursion). **Kahn's algorithm** — repeatedly take nodes with in-degree 0 — mirrors "take whatever course has no unmet prerequisites" and fails cleanly when the queue runs dry before all courses are scheduled.

The traps: `[a, b]` direction (`b` is prerequisite of `a`); returning a partial order when a cycle exists; off-by-one on course labels.

## Kahn's topological sort

Build adjacency list and in-degree array from prerequisites. Enqueue every course with in-degree 0. Dequeue to `order`, decrement in-degree of neighbors, enqueue newly freed courses. If `order.length < numCourses`, a cycle exists — return `[]`.

The invariant: when a course enters `order`, all its prerequisites are already in `order`.

<Steps>
<Step title="Build graph: pre → course">
For `[course, pre]`, edge `pre → course`, increment `indeg[course]`.
</Step>
<Step title="Seed queue with in-degree 0 courses">
These can be taken immediately.
</Step>
<Step title="Process queue, append to order">
Decrement neighbor in-degrees; enqueue at 0.
</Step>
<Step title="Compare order length to numCourses">
Mismatch means cycle — return `[]`.
</Step>
</Steps>

## Solution

```ts
function findOrder(numCourses: number, prerequisites: number[][]): number[] {
  const indeg = new Array(numCourses).fill(0);
  const adj: number[][] = Array.from({ length: numCourses }, () => []);

  for (const [course, pre] of prerequisites) {
    adj[pre].push(course);
    indeg[course]++;
  }

  const queue: number[] = [];
  for (let i = 0; i < numCourses; i++) {
    if (indeg[i] === 0) queue.push(i);
  }

  const order: number[] = [];
  while (queue.length) {
    const u = queue.shift()!;
    order.push(u);
    for (const v of adj[u]) {
      indeg[v]--;
      if (indeg[v] === 0) queue.push(v);
    }
  }

  return order.length === numCourses ? order : [];
}
```

Time **O(V + E)** for V courses and E prerequisites. Space **O(V + E)** for adjacency and in-degree storage.
