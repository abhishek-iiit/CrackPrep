## Nine boxes, one rule — validation must be O(1) per candidate digit

Write a program to solve a 9×9 Sudoku: each row, column, and 3×3 box must contain digits 1–9 exactly once. Modify the board in place; assume a unique solution exists.

Trying digits 1–9 in every empty cell and re-scanning the full row, column, and box each time works on one puzzle but wastes constant factors that matter when backtracking depth reaches 50–60 empty cells. The standard interview approach keeps three (or nine) constraint sets updated on place and undo.

## Find next empty, try valid digits

Scan for the next `'.'` (or use a precomputed list of empty cells). For digits `1`–`9`, skip if already present in row, column, or box. Place digit, mark constraints, recurse. On failure, undo digit and constraint marks.

Box index: `(Math.floor(row / 3) * 3 + Math.floor(col / 3))` for cell `(row, col)`.

<Steps>
<Step title="Initialize constraint sets">
  For each filled cell, mark digit in `rows[r]`, `cols[c]`, `boxes[b]`. Use Sets or boolean arrays of size 10 (index 1–9).
</Step>
<Step title="Locate next empty cell">
  Nested loop or prebuilt empty list. No empty means solved — return true.
</Step>
<Step title="Place, recurse, undo">
  Try digits not in any of the three sets for that cell. On success propagate true; otherwise reset cell to `'.'` and unmark sets.
</Step>
</Steps>

<Callout type="gotcha">
Forgetting to undo constraint marks on backtrack leaves phantom digits in sets — the search dies on false conflicts three levels later. Pair every place with an undo in the same block.
</Callout>

## Solution

```ts
function solveSudoku(board: string[][]): void {
  const rows = Array.from({ length: 9 }, () => new Set<number>());
  const cols = Array.from({ length: 9 }, () => new Set<number>());
  const boxes = Array.from({ length: 9 }, () => new Set<number>());

  for (let r = 0; r < 9; r++) {
    for (let c = 0; c < 9; c++) {
      const ch = board[r][c];
      if (ch === ".") continue;
      const d = ch.charCodeAt(0) - 48;
      const b = Math.floor(r / 3) * 3 + Math.floor(c / 3);
      rows[r].add(d);
      cols[c].add(d);
      boxes[b].add(d);
    }
  }

  function backtrack(): boolean {
    for (let r = 0; r < 9; r++) {
      for (let c = 0; c < 9; c++) {
        if (board[r][c] !== ".") continue;

        const b = Math.floor(r / 3) * 3 + Math.floor(c / 3);
        for (let d = 1; d <= 9; d++) {
          if (rows[r].has(d) || cols[c].has(d) || boxes[b].has(d)) continue;

          board[r][c] = String(d);
          rows[r].add(d);
          cols[c].add(d);
          boxes[b].add(d);

          if (backtrack()) return true;

          board[r][c] = ".";
          rows[r].delete(d);
          cols[c].delete(d);
          boxes[b].delete(d);
        }
        return false; // no digit works here
      }
    }
    return true; // no empty cells
  }

  backtrack();
}
```

Time depends on empty cells and branching — worst case exponential, but constraint propagation is not required for LeetCode's typical puzzles. Space **O(1)** beyond board (fixed 9×9 sets).

## In an interview

Restate: fill empty cells, standard Sudoku rules, one solution, in place. Confirm input uses `'1'..'9'` and `'.'`.

Explain constraint sets for rows, columns, boxes before coding. Say you will return false from a cell when all nine digits fail — that triggers backtrack upstream.

Follow-ups: **Valid Sudoku** (validate without solve), count solutions, or 16×16 variant. Bug to name: not returning false after exhausting digits at a cell, causing infinite search on dead branches.
