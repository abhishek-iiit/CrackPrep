## Three operations, one table

Given strings `word1` and `word2`, convert `word1` into `word2` using insert, delete, and replace — each costing 1. Return the minimum number of operations.

Trying all edit sequences is exponential. The subproblem that repeats: **minimum cost to align the first `i` characters of `word1` with the first `j` of `word2`**. Every optimal edit sequence ends with either a match, an insert into `word1`, a delete from `word1`, or a replace — giving a recurrence with only three neighbors in the table.

The traps: empty string base cases (`dp[i][0] = i` deletes, `dp[0][j] = j` inserts); off-by-one indexing between table and string; using LCS logic when replace is allowed at cost 1.

## The dp recurrence

`dp[i][j]` = min edits for prefixes `word1[0..i-1]` and `word2[0..j-1]`.

- If `word1[i-1] === word2[j-1]`: `dp[i][j] = dp[i-1][j-1]`.
- Else: `1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])` for delete, insert, replace.

Fill row-major or with two rolling rows. Answer at `dp[m][n]`.

## Solution

```ts
function minDistance(word1: string, word2: string): number {
  const m = word1.length;
  const n = word2.length;
  const dp = Array.from({ length: m + 1 }, (_, i) =>
    Array.from({ length: n + 1 }, (_, j) => (i === 0 ? j : j === 0 ? i : 0))
  );

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (word1[i - 1] === word2[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1];
      } else {
        dp[i][j] =
          1 +
          Math.min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]);
      }
    }
  }

  return dp[m][n];
}
```

Time **O(m · n)**. Space **O(m · n)** full table, or **O(min(m,n))** with two rows.

## In an interview

Example: `"horse"` → `"ros"`: replace h→r, delete r, delete s → 3. Confirm all three ops cost 1 and either string may start empty.

State subproblem before coding: `dp[i][j]` = min edits for prefixes. Walk base case row/column.

Follow-ups: print operations, one operation free, only insert/delete. Bug: `dp[i][j]` indexing vs `word1[i]` (use `i-1` for last char).
