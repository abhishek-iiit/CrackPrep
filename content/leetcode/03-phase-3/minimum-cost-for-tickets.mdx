## Passes overlap — buy the cheapest cover for each day

You travel on sorted distinct days `days`. Three pass prices `costs[0]`, `costs[1]`, `costs[2]` cover the next 1, 7, or 30 calendar days from purchase day (including purchase day). Minimize total spend to cover every travel day.

Greedy fails: a cheap 30-day pass might waste coverage, but a 1-day pass every time might beat a 7-day bundle on sparse weeks. Example: days `[1,4,6,7,8,20]` with costs `[2,7,15]` — optimal mix uses 1-day and 7-day passes, not obvious without trying alternatives.

State: **`dp[d]` = minimum cost to cover all travel days in `[1..d]`**. On a travel day, try buying each pass type today and inherit cost from before the pass window starts.

## 1D DP over calendar days

Let `last = days[days.length - 1]`. Build `dp[0..last]`. Use a set of travel days for O(1) lookup.

- Non-travel day `d`: `dp[d] = dp[d-1]` — no new ticket needed.
- Travel day `d`: `dp[d] = min(dp[d-1]+costs[0], dp[d-7]+costs[1], dp[d-30]+costs[2])` with indices clamped at 0.

Answer: `dp[last]`.

<Steps>
<Step title="Put travel days in a Set, set dp[0] = 0">
  Day 0 is a sentinel with zero cost.
</Step>
<Step title="For d = 1..last, skip ticket logic on non-travel days">
  Cost carries forward unchanged.
</Step>
<Step title="On travel days, try 1/7/30-day pass purchases">
  Each option jumps to dp at d-1, d-7, or d-30 plus pass price.
</Step>
</Steps>

## Solution

```ts
function mincostTickets(days: number[], costs: number[]): number {
  const travel = new Set(days);
  const last = days[days.length - 1];
  const dp = new Array(last + 1).fill(0);

  for (let d = 1; d <= last; d++) {
    if (!travel.has(d)) {
      dp[d] = dp[d - 1];
      continue;
    }
    dp[d] = Math.min(
      dp[d - 1] + costs[0],
      dp[Math.max(0, d - 7)] + costs[1],
      dp[Math.max(0, d - 30)] + costs[2]
    );
  }

  return dp[last];
}
```

Time **O(lastDay)** — at most ~365 in examples, up to 10⁴ in constraints. Space **O(lastDay)**.

## In an interview

Example: days `[1,4,6,7,8,20]`, costs `[2,7,15]`. Clarify passes cover calendar days forward, travel days sorted unique.

Define `dp[d]` before coding. Mention non-travel carry-forward.

Follow-ups: arbitrary pass durations, unlimited pass types, print chosen passes. Bug: using `dp[d-7]` without `max(0, d-7)` on early days.
