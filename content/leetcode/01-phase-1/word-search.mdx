## Find a word as a contiguous path in a grid

Given an `m × n` board of characters and a string `word`, return whether `word` exists as a path of adjacent (horizontal or vertical) cells without reusing a cell in the same path. Board `[["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]]`, word `"ABCCED"` → true; `"ABCB"` → false because the second `B` would reuse a cell.

Brute force: try every cell as start, DFS along matching letters. Without backtracking you either revisit cells (wrong) or allocate a fresh `visited` set per path (correct but heavy). The usual interview form **mutates the board temporarily** — replace the cell with `'#'` while exploring, restore on retreat.

## DFS with undo on failure

From `(r,c)`, if out of bounds, already visited, or char mismatch, return false. If index reaches `word.length`, success. Mark cell visited, try four neighbors for index+1, unmark and return false if all fail.

<Steps>
<Step title="Try each cell as start">
  Outer double loop; short-circuit on first success.
</Step>
<Step title="Match and recurse">
  Base case: `index === word.length`. Check `board[r][c] === word[index]`.
</Step>
<Step title="Mark, explore, unmark">
  Save char, set `'#'`, DFS neighbors, restore char — classic backtracking template.
</Step>
</Steps>

Pruning: if current char frequency on board is less than in word, early false — optional on small boards, useful when alphabet is tiny and word is long.

## Solution

```ts
function exist(board: string[][], word: string): boolean {
  const m = board.length;
  const n = board[0].length;

  const dfs = (r: number, c: number, index: number): boolean => {
    if (index === word.length) return true;
    if (r < 0 || c < 0 || r >= m || c >= n) return false;
    if (board[r][c] !== word[index]) return false;

    const saved = board[r][c];
    board[r][c] = "#";

    const found =
      dfs(r + 1, c, index + 1) ||
      dfs(r - 1, c, index + 1) ||
      dfs(r, c + 1, index + 1) ||
      dfs(r, c - 1, index + 1);

    board[r][c] = saved;
    return found;
  };

  for (let r = 0; r < m; r++) {
    for (let c = 0; c < n; c++) {
      if (dfs(r, c, 0)) return true;
    }
  }
  return false;
}
```

Time **O(m n · 4^L)** worst case (`L = word.length`); with pruning and early exit, much better in practice. Space **O(L)** recursion depth.

## In an interview

Clarify adjacency (4-direction, no diagonal), reuse rule, and case sensitivity. Example: path exists vs reuse blocked.

Before coding, say DFS + backtracking with mark/unmark. Mention trying every start cell.

Bug to volunteer: forgetting to restore the cell after failed branches (corrupts later starts); off-by-one on index when comparing chars. Follow-ups: return the path coordinates; 02.23 Word Search II with many words; wrap-around board variants.
