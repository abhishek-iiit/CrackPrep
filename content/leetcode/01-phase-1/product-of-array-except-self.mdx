## Product of everyone else, no division

Return an array `answer` where `answer[i]` is the product of all elements of `nums` except `nums[i]`. The follow-up constraint that usually matters: solve it in O(n) time **without using division**, and ideally O(1) extra space besides the output array.

The division trick — multiply everything, divide by `nums[i]` — breaks on zeros (division by zero) and is explicitly banned. Two nested loops give O(n²), which fails at n = 10⁵.

The structural fact: `answer[i]` equals (product of `nums[0..i-1]`) × (product of `nums[i+1..n-1]`). Those two products are independent and each computable in a prefix/suffix sweep.

## Prefix into output, suffix on the fly

First pass left to right: fill `answer[i]` with the product of all elements to the left of `i`. Use a running `prefix` variable starting at 1.

Second pass right to left: multiply each `answer[i]` by a running `suffix` product of everything to the right. Update `suffix` as you go.

Example: `nums = [1, 2, 3, 4]`. After pass one, `answer = [1, 1, 2, 6]`. Pass two folds in right-side products → `[24, 12, 8, 6]`.

<Steps>
<Step title="Initialize answer array of length n">
  First pass will write prefix products directly into it.
</Step>
<Step title="Left-to-right: answer[i] = product of nums[0..i-1]">
  Maintain running `prefix`, multiply after writing each slot.
</Step>
<Step title="Right-to-left: answer[i] *= product of nums[i+1..n-1]">
  Maintain running `suffix`, multiply before decrementing index.
</Step>
</Steps>

<Callout type="note">
Zero in the input: one zero makes most entries 0; two zeros make the entire output zero. The prefix/suffix method handles this without special cases — any prefix containing a zero zeroes out the rest of that side.
</Callout>

## Solution

```ts
function productExceptSelf(nums: number[]): number[] {
  const n = nums.length;
  const answer = new Array<number>(n);

  let prefix = 1;
  for (let i = 0; i < n; i++) {
    answer[i] = prefix;
    prefix *= nums[i];
  }

  let suffix = 1;
  for (let i = n - 1; i >= 0; i--) {
    answer[i] *= suffix;
    suffix *= nums[i];
  }

  return answer;
}
```

Time **O(n)**, space **O(1)** auxiliary excluding the output array (two scalar accumulators).

## In an interview

Paraphrase with example: `[1, 2, 3, 4]` → `[24, 12, 8, 6]`. Confirm: no division, O(n) time, minimize extra space.

Explain that index `i` splits the array into left and right products. Draw the two-pass reuse of the output array before coding.

Follow-ups: handle overflow (use bigint or log sums), sparse arrays, or streaming input. Bug to mention: allocating separate prefix and suffix arrays when the interviewer asked for O(1) extra — the output array counts as allowed storage.
