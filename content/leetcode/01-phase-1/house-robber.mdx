## Rob two neighbors and the alarm trips

Each house holds a non-negative amount of money. Robbing **adjacent** houses triggers the alarm, so you want the maximum you can take from a linear street without picking neighbors. `[2,7,9,3,1]` → `12` by taking `2 + 9 + 1`.

Greedy fails immediately: the richest house might sit between two other rich houses, and skipping it frees both neighbors. Try `[2,1,9,1,2]` — grabbing `9` alone gives 9, but `2 + 1 + 2` across the ends gives 5; the optimal path is `2 + 9 + 2 = 13` by skipping the ones beside 9. You need a decision at every house: **take it** (and forfeit the previous) or **skip it** (keep whatever you had).

## The rob-or-skip recurrence

Define `dp[i]` as the max loot from houses `0..i`. At house `i`, either you rob it — `nums[i] + dp[i-2]` — or you skip — `dp[i-1]`. Base cases: `dp[0] = nums[0]`, `dp[1] = max(nums[0], nums[1])`.

The invariant: `dp[i]` always reflects the best **legal** loot ending at or before `i`; you never need to remember which houses were chosen, only the numeric optimum.

You only need the last two values. Track `prev2` (best up to i-2) and `prev1` (best up to i-1); at each house, `cur = max(prev1, prev2 + nums[i])`, then shift.

## Solution

```ts
function rob(nums: number[]): number {
  if (nums.length === 0) return 0;
  if (nums.length === 1) return nums[0];

  let prev2 = nums[0];
  let prev1 = Math.max(nums[0], nums[1]);

  for (let i = 2; i < nums.length; i++) {
    const cur = Math.max(prev1, prev2 + nums[i]);
    prev2 = prev1;
    prev1 = cur;
  }
  return prev1;
}
```

Time **O(n)**, space **O(1)**. A full `dp` array is **O(n)** space and acceptable in an interview, but rolling variables show you see the dependency structure.

## In an interview

State the constraint: max sum, no two adjacent. Give the tiny counterexample where local greed on the max element loses. Write the recurrence in words before code: "best at i is max of skip i or take i plus best at i-2."

Follow-ups arrive fast: **House Robber II** (circular street), **House Robber III** (binary tree), or "return the indices." For II, say you would run this linear solution twice. Mention empty array → 0 and single house → that house's value before diving in.

The common bug: using `dp[i-1] + nums[i]` — that robs neighbors. The correct take branch always jumps back two indices.
