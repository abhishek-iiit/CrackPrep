## Same shape, new nodes — shared references are the bug

Each node has a value and a list of neighbors. Return a **deep copy** of the graph starting from a reference node. The copy must have new node objects; pointing new neighbors at old nodes is wrong.

Naive DFS that creates a node whenever it sees a value duplicates work when the graph has cycles — you re-enter the same neighbor and allocate again. Without a map from old → new, you cannot tell "already cloned" from "first visit."

## Traverse with an old-to-new map

Whether BFS or DFS, the pattern is identical: if `old` is in the map, return the existing clone; otherwise create `clone = new Node(old.val)`, store `map.set(old, clone)`, then attach neighbors by recursively (or iteratively) cloning each neighbor and pushing onto `clone.neighbors`.

The invariant: every edge in the original has exactly one corresponding edge between the mapped endpoints in the copy, and no clone node is created twice for the same original.

<Steps>
<Step title="Seed the map on first visit">
On encountering `node`, if mapped, return clone. Else allocate clone and record mapping **before** descending — that breaks cycles safely.
</Step>
<Step title="Clone neighbors">
For each `neighbor` in `node.neighbors`, `clone.neighbors.push(cloneGraph(neighbor))` in DFS, or enqueue unvisited neighbors in BFS after linking.
</Step>
<Step title="Return the clone of the start">
If input is null, return null. Otherwise return `map.get(start)` or the DFS result on the reference.
</Step>
</Steps>

## Solution

```ts
class GraphNode {
  val: number;
  neighbors: GraphNode[];
  constructor(val?: number, neighbors?: GraphNode[]) {
    this.val = val ?? 0;
    this.neighbors = neighbors ?? [];
  }
}

function cloneGraph(node: GraphNode | null): GraphNode | null {
  if (!node) return null;
  const map = new Map<GraphNode, GraphNode>();

  function dfs(old: GraphNode): GraphNode {
    if (map.has(old)) return map.get(old)!;
    const copy = new GraphNode(old.val);
    map.set(old, copy);
    for (const nei of old.neighbors) {
      copy.neighbors.push(dfs(nei));
    }
    return copy;
  }

  return dfs(node);
}
```

Time **O(V + E)** — each node and edge visited once. Space **O(V)** for the map and recursion stack (BFS uses a queue instead of stack depth).

## In an interview

Define the node shape. Emphasize **deep copy** — new objects, same topology. Draw a triangle graph and show why revisiting node 1 without a map creates duplicates.

Say you will keep `Map<original, clone>` and create the clone before recursing into neighbors. BFS is fine if you prefer a queue.

Follow-ups: **Clone Graph** with n nodes given as adjacency list by index, **Copy List with Random Pointer**, or serialize to string. Bug to flag: mapping by `val` when values repeat — always key on object reference.
