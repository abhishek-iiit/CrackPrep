## One digit or two — unless the slice starts with zero

A message encoded as digits maps `1→A` through `26→Z`. Given a digit string, count how many decodings exist. `"12"` → `2` (`(1,2)` and `(12)`). `"226"` → `3`. `"06"` → `0` — a leading zero on a one-digit chunk is not a letter.

Brute force tries every split recursively. A string of length 100 forks at each position; that is **O(2^n)** without memo. The overlapping subproblems are obvious: the number of ways to decode `s[i..]` depends only on `i`, not on how you arrived there.

## Prefix DP with a zero guard

Let `dp[i]` = ways to decode `s[i..]`. From `i`, take one digit if `s[i] !== '0'` (zero alone is invalid), or two digits if `10 ≤ int(s[i..i+2]) ≤ 26`.

Transition: `dp[i] = (valid one-digit ? dp[i+1] : 0) + (valid two-digit ? dp[i+2] : 0)`. Base: `dp[n] = 1` (empty suffix — one way to decode nothing). Fill from right to left, or recurse with memo on index.

<Callout type="gotcha">
`"10"` and `"20"` are valid (J and T). `"30"`, `"06"`, and `"100"` are not — the two-digit window must be 10–26, and a lone `'0'` at any position kills every path through it. Check one-digit validity before adding `dp[i+1]`.
</Callout>

## Solution

```ts
function numDecodings(s: string): number {
  const n = s.length;
  if (n === 0 || s[0] === "0") return 0;

  const dp = new Array<number>(n + 1).fill(0);
  dp[n] = 1;

  for (let i = n - 1; i >= 0; i--) {
    if (s[i] === "0") {
      dp[i] = 0;
      continue;
    }
    dp[i] = dp[i + 1];
    if (i + 1 < n) {
      const two = parseInt(s.slice(i, i + 2), 10);
      if (two >= 10 && two <= 26) dp[i] += dp[i + 2];
    }
  }
  return dp[0];
}
```

Time **O(n)**, space **O(n)** for the table — compress to **O(1)** by keeping only `next` and `nextNext` if asked. The parse on two characters is constant work per index.

## In an interview

Restate mapping and give `"12"` vs `"06"`. Say: "At each index I can take one or two digits if valid; count paths to the end." Write the recurrence before the loop.

Follow-ups: return all decodings, handle `"100"` (answer 0), or "what if `*` can be 1–9?" (Decode Ways II — multiply counts and mod). Mention empty string edge case and that `s[0] === '0'` returns 0 immediately.

Bug to volunteer: treating any two-digit number ≤ 26 as valid without requiring ≥ 10 — that makes `"06"` decode as `0+6`.
