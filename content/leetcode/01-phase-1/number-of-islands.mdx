## Count connected components of land in a sea of water

A binary grid: `'1'` land, `'0'` water. An island is land connected **4-directionally** (up/down/left/right). Return the island count. Four `'1'`s in a square but not diagonally touching are one island if they share edges.

Nested loops that flood-fill without marking visited cells revisit the same island forever. Brute force BFS from every `'1'` works if you **sink** visited land — otherwise you double-count.

## One pass: start DFS/BFS only on unvisited land

Scan the grid. When you find `'1'`, increment the count and run flood-fill (DFS or BFS) to mark every connected `'1'` as visited — flip to `'0'` or use a separate `visited` set.

The invariant: each `'1'` belongs to exactly one flood-fill launch; after a fill, no cell in that component remains `'1'`.

DFS is usually shorter to write; BFS avoids recursion depth on snake-shaped islands (roughly **mn** cells in one component — rare in interviews but worth mentioning).

<Steps>
<Step title="Scan every cell">
For each `(r,c)` with `'1'`, increment `count`.
</Step>
<Step title="Flood-fill">
DFS/BFS four neighbors in bounds with value `'1'`, mark as visited by setting `'0'`.
</Step>
<Step title="Continue scan">
Do not restart fill from cells already sunk — the outer loop skips `'0'`.
</Step>
</Steps>

## Solution

```ts
function numIslands(grid: string[][]): number {
  const m = grid.length;
  const n = grid[0].length;
  let count = 0;

  function dfs(r: number, c: number): void {
    if (r < 0 || r >= m || c < 0 || c >= n || grid[r][c] === "0") return;
    grid[r][c] = "0";
    dfs(r + 1, c);
    dfs(r - 1, c);
    dfs(r, c + 1);
    dfs(r, c - 1);
  }

  for (let r = 0; r < m; r++) {
    for (let c = 0; c < n; c++) {
      if (grid[r][c] === "1") {
        count++;
        dfs(r, c);
      }
    }
  }
  return count;
}
```

Time **O(m × n)** — each cell visited once. Space **O(m × n)** worst-case recursion stack for a snake island; BFS queue same bound. Mutating the grid avoids extra memory.

## In an interview

Define 4-connectivity with a tiny example — diagonal `'1'`s are not one island unless 8-dir stated. Propose: scan, on `'1'` increment and flood-fill marking visited.

Follow-ups: **Max Area of Island**, **Surrounded Regions** (fill from border water first), **Number of Distinct Islands** (hash shapes). Clarify whether input can be mutated.

Bug to name: forgetting to mark visited inside DFS and counting infinite revisits — or using 8-direction moves when the problem says 4.
