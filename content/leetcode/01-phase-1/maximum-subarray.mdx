## Which contiguous block sums the most?

Given an integer array, find the contiguous subarray with the largest sum and return that sum. At least one element must be included — the subarray has length ≥ 1.

Brute force tries every `(start, end)` pair: O(n²) subarrays, O(n) sum each → O(n³), or O(n²) with a running sum. n = 10⁵ makes that impossible.

Kadane's algorithm is the standard linear scan. The decision at each index: does the best subarray ending here extend the previous best, or start fresh at this element?

## Kadane: extend or restart

Track `currentSum` — max sum of a subarray ending at the current index — and `maxSum` — global best.

At each `nums[i]`: `currentSum = max(nums[i], currentSum + nums[i])`. Then `maxSum = max(maxSum, currentSum)`.

The invariant: after processing index `i`, `currentSum` is the optimal sum among subarrays that must end at `i`.

Walk `[−2, 1, −3, 4, −1, 2, 1, −5, 4]`. The winning block `[4, −1, 2, 1]` sums to 6. Negative running totals get discarded because starting over at the next positive beat carrying debt forward.

## Solution

```ts
function maxSubArray(nums: number[]): number {
  let currentSum = nums[0];
  let maxSum = nums[0];

  for (let i = 1; i < nums.length; i++) {
    currentSum = Math.max(nums[i], currentSum + nums[i]);
    maxSum = Math.max(maxSum, currentSum);
  }

  return maxSum;
}
```

Time **O(n)**, space **O(1)**.

## In an interview

State contiguous, non-empty subarray, maximize sum. Example: all negatives `[-1]` → answer `-1`, not 0.

Explain the local choice: best ending here is either extend or restart. Code Kadane in five lines.

Follow-ups: return indices, circular array, at most k elements. Bug: initializing `maxSum` to 0 when all entries are negative — seed with `nums[0]`.
