## Walk the perimeter, then the next inner perimeter

Return all elements of an `m × n` matrix in clockwise spiral order. `[[1,2,3],[4,5,6],[7,8,9]]` yields `[1,2,3,6,9,8,7,4,5]`.

Simulating "direction" with a turn rule (right → down → left → up) works but needs careful handling when you hit a wall or a cell already visited. The **boundary shrink** version is easier to reason about: maintain `top`, `bottom`, `left`, `right`, walk each side of the current rectangle, then move the corresponding boundary inward. Stop when `top > bottom` or `left > right`.

## Four sides, four bounds

<Steps>
<Step title="Left to right along top row">
  `i` from `left` to `right` at row `top`. Then `top++`.
</Step>
<Step title="Top to bottom along right column">
  `i` from `top` to `bottom` at col `right`. Then `right--`.
</Step>
<Step title="Right to left along bottom row (if top ≤ bottom)">
  Prevents double-counting a single row. Then `bottom--`.
</Step>
<Step title="Bottom to top along left column (if left ≤ right)">
  Same guard for a single column. Then `left++`.
</Step>
</Steps>

The `if (top <= bottom)` and `if (left <= right)` guards are not optional — without them a 1×n or m×1 matrix visits its cells twice.

## Solution

```ts
function spiralOrder(matrix: number[][]): number[] {
  const result: number[] = [];
  let top = 0;
  let bottom = matrix.length - 1;
  let left = 0;
  let right = matrix[0].length - 1;

  while (top <= bottom && left <= right) {
    for (let c = left; c <= right; c++) result.push(matrix[top][c]);
    top++;

    for (let r = top; r <= bottom; r++) result.push(matrix[r][right]);
    right--;

    if (top <= bottom) {
      for (let c = right; c >= left; c--) result.push(matrix[bottom][c]);
      bottom--;
    }

    if (left <= right) {
      for (let r = bottom; r >= top; r--) result.push(matrix[r][left]);
      left++;
    }
  }

  return result;
}
```

Time **O(m n)**, space **O(1)** excluding the output array.

## In an interview

State output order with a 3×3 example. Mention 1×1 and 1×4 edge shapes. Choose boundary shrink and say why guards on the bottom and left legs matter.

Bug to volunteer: omitting guards and duplicating cells on skinny matrices. Follow-ups: spiral matrix II (generate n×n); rotate layers (related to 01.48 Rotate Image).
