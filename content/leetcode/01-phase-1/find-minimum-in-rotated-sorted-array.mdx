## Sorted, then rotated at one pivot

A strictly ascending array was rotated at unknown index k: `[3, 4, 5, 1, 2]` came from `[1, 2, 3, 4, 5]`. Find the minimum in O(log n) time. All values are distinct.

Linear scan is O(n) — works but ignores the structure. The structure: at most one "drop" where `nums[i] > nums[i+1]`; the element after the drop is the minimum. Binary search finds that drop without walking every index.

Compare `nums[mid]` to `nums[right]` (not `nums[left]` — the left comparison has an off-by-one pitfall when `left === mid`). If `nums[mid] > nums[right]`, the minimum lies strictly to the right of `mid` — the left half including mid is sorted and entirely above the tail. Otherwise the minimum is at `mid` or left of it — shrink `right = mid`.

## Binary search on the rotation point

Invariant: the minimum is always in `[left, right]`. Loop while `left < right`. Never use `left <= right` with `right = mid` — infinite loop.

When loop ends, `left === right` at the minimum index.

Example `[4, 5, 6, 7, 0, 1, 2]`: mid 7 > right 2 → search right. Eventually narrow to index of 0.

<Callout type="gotcha">
Using `nums[mid] >= nums[left]` to decide direction fails on `[2, 1]` — both sides look "sorted" from the left. Anchoring against `nums[right]` avoids that asymmetry.
</Callout>

## Solution

```ts
function findMin(nums: number[]): number {
  let left = 0;
  let right = nums.length - 1;

  while (left < right) {
    const mid = left + Math.floor((right - left) / 2);
    if (nums[mid] > nums[right]) {
      left = mid + 1;
    } else {
      right = mid;
    }
  }

  return nums[left];
}
```

Time **O(log n)**, space **O(1)**.

## In an interview

Draw rotated sorted array, mark the drop. State distinct values, O(log n). Explain why compare to `nums[right]`.

Walk `[3,4,5,1,2]` on the whiteboard. Before coding, note `right = mid` not `mid - 1` on the left branch.

Follow-ups: with duplicates, find peak in rotated array, 01.08 search target. Bug: infinite loop from `left = mid` when it should be `left = mid + 1`.
