## One number at a time wastes work

Given `n`, return an array `ans` where `ans[i]` is the number of set bits in the binary form of `i`, for every `i` from `0` to `n`. Calling 01.12 Number of 1 Bits on each `i` independently costs **O(n log n)** — roughly n numbers times up to 32 bit operations each.

The numbers `0..n` are not independent. Every integer either drops the lowest set bit from a smaller value, or — in another framing — inherits its parent's popcount plus one. Either recurrence fills the whole table in one pass.

For `n = 5`:

| i | binary | ans[i] | i & (i-1) |
|---|--------|--------|-----------|
| 0 | 0 | 0 | — |
| 1 | 1 | 1 | 0 → ans[0]+1 |
| 2 | 10 | 1 | 0 → ans[0]+1 |
| 3 | 11 | 2 | 2 → ans[2]+1 |
| 4 | 100 | 1 | 0 → ans[0]+1 |
| 5 | 101 | 2 | 4 → ans[4]+1 |

Notice: `ans[i] = ans[i & (i-1)] + 1`. Clearing the lowest 1 from `i` lands at a strictly smaller index whose popcount you already computed.

## Two O(n) recurrences

**Recurrence A — lowest-bit drop:** `dp[i] = dp[i & (i - 1)] + 1`. Each step removes exactly one set bit; the subproblem is smaller.

**Recurrence B — right shift:** `dp[i] = dp[i >> 1] + (i & 1)`. The popcount of `i` equals the popcount of `i` with the last bit chopped off, plus whether that last bit is 1.

Both are **O(n)** time, **O(n)** space for the output array. Pick whichever is easier to explain on the day.

<Steps>
<Step title="Seed dp[0] = 0">Zero has no set bits.</Step>
<Step title="Fill i from 1 to n">`dp[i] = dp[i & (i - 1)] + 1` (or the shift variant).</Step>
<Step title="Return dp">No backtracking — one forward pass.</Step>
</Steps>

## Solution

```ts
function countBits(n: number): number[] {
  const dp = new Array<number>(n + 1).fill(0);
  for (let i = 1; i <= n; i++) {
    dp[i] = dp[i & (i - 1)] + 1;
  }
  return dp;
}
```

Time **O(n)**. Space **O(n)** for the output (required anyway).

## In an interview

Restate: return popcount for every number from 0 to n. Start with the naive "call hamming weight n times" and its cost. Then show `i & (i-1)` clears the lowest 1 — so `dp[i] = dp[i & (i-1)] + 1`. Walk `i = 5`: `5 & 4 = 4`, `dp[4] = 1`, answer 2.

Follow-ups: explain the `i >> 1` variant, use popcount for a bitmask DP problem, or "what if you only need numbers that are powers of two?"

Bug to mention: off-by-one on the loop bound — you need `i <= n`, not `i < n`, or you drop the last entry.
