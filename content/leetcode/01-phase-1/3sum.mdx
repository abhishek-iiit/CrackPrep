## Three numbers, zero sum, no duplicate triplets

Return all unique triplets `[nums[i], nums[j], nums[k]]` such that `i ≠ j ≠ k` and the three values sum to 0. The output must not contain duplicate triplets — `[-1, 0, 1]` appears once even if `-1` and `1` sit at multiple indices.

Triple nested loops are O(n³) — too slow at n = 3000. Sorting unlocks two-pointer search on the remaining pair after fixing one index.

This is 01.01 Two Sum's upgrade: instead of a hash map for one complement, sort and sweep with two pointers for O(n²) total after O(n log n) sort.

## Sort, anchor, two-pointer scan

Sort ascending. For each index `i` from 0 to n−3:

1. Skip duplicate anchors: if `i > 0 && nums[i] === nums[i-1]`, continue.
2. Set `left = i + 1`, `right = n - 1`.
3. While `left < right`: if sum === 0, record triplet and advance both pointers past duplicates; if sum < 0, `left++`; else `right--`.

Duplicate skipping at anchor and at hit time is non-optional. Without it you emit `[-1,-1,0,0,1,1]` style repeats until the judge rejects you.

Example `[-1, 0, 1, 2, -1, -4]` → `[[-1,-1,2], [-1,0,1]]` after sort `[-4,-1,-1,0,1,2]`.

<Callout type="warn">
Forgetting to skip equal `nums[left]` and `nums[right]` after a hit is the most common failure — you find the same triplet again on the next iteration.
</Callout>

## Solution

```ts
function threeSum(nums: number[]): number[][] {
  nums.sort((a, b) => a - b);
  const result: number[][] = [];

  for (let i = 0; i < nums.length - 2; i++) {
    if (i > 0 && nums[i] === nums[i - 1]) continue;

    let left = i + 1;
    let right = nums.length - 1;

    while (left < right) {
      const sum = nums[i] + nums[left] + nums[right];
      if (sum === 0) {
        result.push([nums[i], nums[left], nums[right]]);
        while (left < right && nums[left] === nums[left + 1]) left++;
        while (left < right && nums[right] === nums[right - 1]) right--;
        left++;
        right--;
      } else if (sum < 0) {
        left++;
      } else {
        right--;
      }
    }
  }

  return result;
}
```

Time **O(n²)** after sort, space **O(1)** auxiliary excluding output (sort may use O(log n) stack).

## In an interview

Paraphrase: unique triplets summing to zero. Example with duplicates. State O(n²) target.

Outline: sort → for each i, two-sum on remainder with dedup rules. Mention anchor skip and post-hit skip before coding.

Follow-ups: 3Sum Closest, 4Sum (outer loop + inner 3Sum or two two-pointer layers), k-Sum recursion. Bug: pushing triplets without advancing past duplicate left/right values.
