## Flip every `next` pointer in place

Given `1 → 2 → 3 → null`, return `3 → 2 → 1 → null`. Copy values into an array, reverse, rebuild — O(n) time but O(n) extra space and not what the problem asks. The in-place requirement means rewiring `next` fields only, constant extra space.

The iterative pattern uses three pointers: `prev` (reversed prefix), `curr` (node being rewired), `next` (saved successor so the list is not lost mid-flip).

## Iterative three-pointer walk

Initialize `prev = null`, `curr = head`. While `curr` exists:

1. Save `next = curr.next`.
2. Set `curr.next = prev` — reverse the link.
3. Advance: `prev = curr`, `curr = next`.

When `curr` is null, `prev` is the new head.

<Steps>
<Step title="Save the rest">
`next = curr.next` before mutating — otherwise you lose the tail.
</Step>
<Step title="Reverse one link">
`curr.next = prev` points backward.
</Step>
<Step title="Slide the window">
Move `prev` and `curr` one step forward.
</Step>
</Steps>

## Solution

```ts
class ListNode {
  val: number;
  next: ListNode | null;
  constructor(val?: number, next?: ListNode | null) {
    this.val = val ?? 0;
    this.next = next ?? null;
  }
}

function reverseList(head: ListNode | null): ListNode | null {
  let prev: ListNode | null = null;
  let curr = head;

  while (curr) {
    const next = curr.next;
    curr.next = prev;
    prev = curr;
    curr = next;
  }

  return prev;
}
```

Time **O(n)**, space **O(1)**.

Recursive form (optional): reverse the tail, attach `head` after the new head, set `head.next = null`. Same O(n) time, **O(n)** stack space — fine to mention, iterative is usually preferred in interviews.

## In an interview

Draw three nodes. State invariant: `prev` is the head of the reversed prefix, `curr` is next to process. Empty list and single node return unchanged. Code the loop; return `prev`.

Follow-ups: reverse between m and n, reverse k-group, palindrome linked list (reverse second half). Bug to call out before running: forgetting to save `next` before setting `curr.next = prev` — the remainder of the list disappears.
