## One word at a time revisits the same paths

Given an m×n board of characters and a list of words, return every word that can be formed by sequentially adjacent cells (no reuse per path). The board can be up to 12×12; the word list up to 10³ entries with total length up to 10⁵.

Running 01.49 Word Search independently for each dictionary word is O(words × m × n × 4^L) — the same board cells and prefixes get rediscovered thousands of times. `"apple"` and `"app"` share a three-cell path on the board; naive per-word DFS explores that prefix twice. With 10³ words on a 144-cell board, you need shared pruning, not repeated blind search.

## One trie, DFS from every cell

Insert all words into a trie (02.21). From each board cell, DFS along trie edges:

- Move to neighbor if the character matches a trie child.
- Track visited cells with backtracking (mark/unmark).
- When a node has `isEnd`, record the word. **Remove the word from the trie** (clear `isEnd` and prune empty branches) or collect in a set to avoid duplicates.

The invariant: the trie node reached after k steps equals the prefix formed by the path so far. If no child exists for the next character, backtrack immediately — you prune entire subtrees of the dictionary at once.

  If board[r][c] matches a root child, descend and explore four directions.

<Step title="On isEnd, push word and prune">
  Remove word from trie so you do not report it again from another start cell.
</Step>
<Step title="Backtrack visited marks">
  Same as 01.49 — unmark cell when returning from recursion.
</Step>

## Solution

```ts
class TrieNode {
  children: Map<string, TrieNode> = new Map();
  word: string | null = null;
}

function findWords(board: string[][], words: string[]): string[] {
  const root = new TrieNode();
  for (const w of words) {
    let node = root;
    for (const ch of w) {
      if (!node.children.has(ch)) node.children.set(ch, new TrieNode());
      node = node.children.get(ch)!;
    }
    node.word = w;
  }

  const res: string[] = [];
  const rows = board.length, cols = board[0].length;

  function dfs(r: number, c: number, node: TrieNode): void {
    const ch = board[r][c];
    const next = node.children.get(ch);
    if (!next) return;

    if (next.word) {
      res.push(next.word);
      next.word = null; // avoid duplicates
    }

    board[r][c] = '#'; // mark visited
    for (const [dr, dc] of [[0,1],[0,-1],[1,0],[-1,0]]) {
      const nr = r + dr, nc = c + dc;
      if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && board[nr][nc] !== '#') {
        dfs(nr, nc, next);
      }
    }
    board[r][c] = ch; // unmark
  }

  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      dfs(r, c, root);
    }
  }
  return res;
}
```

Time **O(m × n × 4^L)** in the worst case per start cell, but trie pruning cuts branches early; total work is bounded by board exploration with dictionary-guided cutoff. Space **O(total word length)** for the trie plus O(L) recursion stack.

## In an interview

Restate: 4-directional adjacency, no cell reuse within one path, return all matches (order usually ignored). Walk through a 2×2 example with overlapping words.

Explain the two-layer idea: board DFS (same backtracking as 01.49) guided by trie edges (from 02.21). The insight sentence: **the trie tells you when to stop early** — if `'x'` has no child from the current node, every word still in that subtree is impossible from this path.

Mention duplicate handling before asked: clearing `word` at terminal nodes or deleting the branch. Proactive bug: forgetting to unmark visited cells — the board becomes unusable for other paths.

Follow-ups: return coordinates of paths, handle duplicate words in input, or 3D grid variant.
