## Delimiters break when the payload contains them

Design an encoder/decoder for a list of strings into one string and back. The input words can contain any characters — letters, digits, `#`, commas, Unicode — and the round trip must be lossless.

The naive join `strs.join(',')` dies the moment a word contains a comma: `["hello,world", "foo"]` encodes ambiguously. Escaping helps but gets ugly when the escape character itself appears in data. Length-prefix framing sidesteps the ambiguity: store **how many characters follow**, then a separator, then exactly that many bytes — no scanning for terminators inside the payload.

This is the same idea as TLV fields on the wire and length-prefixed protobuf strings: the reader never guesses where a field ends.

## Length, delimiter, payload — repeat

For each word `w`, append `len(w) + '#' + w`. The `#` separates the length digits from the payload only when lengths are written in decimal without `#` in the length itself — decimal length never contains `#`.

Decoder walks the buffer:

1. Read digits until `#` → length L.
2. Skip `#`.
3. Take the next L characters as one word.
4. Continue from the byte after the payload.

No backtracking, no escape rules, no dependence on alphabet.

  Concatenate all encoded chunks into one string.

<Step title="Decode: parse length until '#'">
  Integer parse the prefix; advance past `#`.
</Step>
<Step title="Slice exactly len characters as the next word">
  Push to result; move index forward by len.
</Step>
<Step title="Repeat until the buffer is exhausted">
  Empty input list encodes to "" and decodes to [].
</Step>
</Steps>

## Solution

```ts
function encode(strs: string[]): string {
  return strs.map((s) => `${s.length}#${s}`).join("");
}

function decode(s: string): string[] {
  const result: string[] = [];
  let i = 0;

  while (i < s.length) {
    let j = i;
    while (s[j] !== "#") j++;
    const len = parseInt(s.slice(i, j), 10);
    i = j + 1;
    result.push(s.slice(i, i + len));
    i += len;
  }

  return result;
}
```

Time **O(N)** where N is the total number of characters across all strings — each character is written once and read once. Space **O(N)** for the encoded string and the output array.

<Callout type="gotcha">
Using a fixed delimiter without length — `join('|')` — fails when words contain `|`. Escaping every delimiter occurrence in every word works but decode must mirror escape rules exactly; one missed edge case corrupts every field after it. Length-prefix is simpler to prove correct.
</Callout>

## In an interview

Restate round-trip requirement with a malicious input: `["a#b", "##"]` must survive. Confirm empty list, empty strings in the list, and very long words.

Draw one encoded example on the board: `3#cat4#dog#` style. Say decode never searches inside payload for structure — only reads L then L chars.

Follow-ups: binary strings, serialize 2D string matrix, detect corrupted stream. Bug: using `split('#')` on the whole buffer — lengths and payloads get confused when `#` appears inside a word.
